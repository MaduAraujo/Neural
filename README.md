# Neural | O Futuro da IA
  
## Visão Geral do Projeto

O **Neural** é um site web desenvolvido para educar e engajar usuários sobre o tema da Inteligência Artificial, utilizando um design futurista e elementos interativos. 
O principal objetivo é desmistificar conceitos complexos (como Redes Neurais, ANI, AGI e ASI) e apresentar as tecnologias de IA generativa de forma acessível e visualmente atraente.

## Funcionalidades Principais

O site está dividido em seções principais, cada uma focada em um aspecto da IA:
  
  * **Toggle de Tema:** Alterna entre modo escuro (padrão) e modo claro.
  * **Níveis de Evolução:** Detalha os estágios da IA: **ANI**, **AGI** e **ASI**.
  * **Aplicações:** Demonstrações de IA Generativa (NLP, Visão Computacional, Automação).
  * **O Código Fonte:** Apresenta as principais linguagens de programação usadas em IA (Python, C++, JS, R).
  * **O Dilema Ético:** Aborda questões cruciais como transparência e viés algorítmico.
  * **Jogos Interativos:**
      * **Desafio Neural:** Teste de múltipla escolha para validar o aprendizado do usuário.
      * **Mini-Game:** Jogo de Pedra, Papel, Tesoura onde a máquina tenta prever o movimento do jogador.
      * **Teste de IA ao Vivo:** Seção preparada para receber um modelo de **Teachable Machine** para reconhecimento em tempo real via webcam.

## Tecnologias Utilizadas

| Categoria | Tecnologia | Uso |
| :--- | :--- | :--- |
| **Estrutura** | HTML5 | Semântica e organização do conteúdo. |
| **Estilização** | CSS3 (Puro) | Design futurista, variáveis CSS para tema (Dark/Light Mode), e animações. |
| **Interatividade** | JavaScript (Puro) | Lógica de jogos, Toggle de Tema, Efeitos Typewriter e Scroll Reveal. |
| **Bibliotecas** | Font Awesome | Ícones para enriquecer a interface. |
| **IA/Webcam** | Teachable Machine (TF.js) | Scripts externos pré-configurados para a seção de Demo ao Vivo. |

## Como Acessar e Rodar o Projeto

### Pré-requisitos

  * Navegador web moderno (Chrome, Firefox, Edge).
  * Um editor de código (VSCode é recomendado).

### 1. Clonar o Repositório

```bash
# Clone o repositório para sua máquina local
git clone https://github.com/MaduAraujo/Neural.git

# Entre na pasta do projeto
cd Neural
```

### 2. Abrir o Projeto

O projeto não exige instalação de dependências.

1.  Localize o arquivo `index.html` dentro da pasta clonada.
2.  Clique duas vezes no arquivo `index.html` ou use a função "Open with Live Server" (se estiver usando VSCode) para abrir o site no seu navegador.

O site deve ser carregado imediatamente, e as funcionalidades estarão ativas.
